# 실제 도면 테스트 세트

부품 하나에 폴더 하나. 원본 Fusion 모델이 있으면 그게 정답이라 자동 비교가 가능합니다.

```
real/
  <부품이름>/
    drawing.pdf        Fusion 도면 작업공간에서 내보낸 PDF (있으면)
    drawing.dxf        같은 도면의 DXF (있으면)
    photo.jpg          사진·스캔 도면 (있으면)
    original.f3d       원본 모델 = 정답 (있으면)
    notes.md           재질, 출처, 특이사항 (선택)
```

- 파일 이름은 위와 같지 않아도 됩니다. 폴더에 넣기만 하면 Claude가 정리합니다.
- 인터넷에서 받은 도면은 `notes.md`에 출처와 라이선스를 적어 주세요.
- 회사·학교 등 외부 공개하면 안 되는 도면은 `private_` 로 시작하는 폴더에 넣으세요 (나중에 GitHub에 올려도 제외됨).
