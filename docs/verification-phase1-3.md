## 3. 검증 중 발견해서 고친 것

| 증상 | 원인 | 조치 |
|---|---|---|
| 플랜지 파라미터 등록 실패 | `pcd`도 Fusion 단위 이름 | 거부되면 즉시 `pcd_`로 바꿔 등록 |
| 플랜지 DXF 볼트 구멍 0개 (검증이 E403/E404로 잡음) | 여러 원 관통 컷이 허브 바닥면 높이에서 경고 상태로 실패 | 경고면 지우고 거리 컷으로 재생성, 빌드 로그에 "자동 보정" 기록 |
| 평면도 구멍을 못 찾음 | 구멍 원이 외곽선과 닿지 않아 다른 뷰로 분리됨 | 다른 뷰 상자 안에 들어간 묶음은 그 뷰에 합침 |
| 1면도의 외곽선이 사라짐 | 전체를 감싸는 사각형을 테두리로 오인 | 안에 표제란 글자가 있을 때만 테두리로 판단 |
| 처음 DXF 실행 때 ezdxf 설치 후에도 실패 | 사용자 site-packages 폴더가 실행 중에 새로 생김 | 설치 직후 그 폴더를 경로에 추가 |
| 파일 전송이 가끔 옛 내용으로 덮임 (개발 환경 문제) | 같은 경로를 연속으로 보낼 때 캐시 | 매번 새 이름으로 올린 뒤 원래 경로에 씀 |
