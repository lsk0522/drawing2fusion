# pdf-reading.md — 벡터 PDF 도면 읽기

`python -m d2f run 도면.pdf` (또는 `run.bat`에 끌어다 놓기, Fusion 패널의 **도면 열기**).
CAD 프로그램에서 **PDF로 내보낸 도면**(선이 벡터로 들어 있는 PDF)을 읽습니다. 스캔·사진 PDF는 선이 없어서
`E103`으로 멈추고 채팅 판독([image-reading.md](image-reading.md))을 안내합니다.

코드: `d2f/extract/pdf_reader.py` → 결과를 DXF와 같은 형태(선·원·호, 글자, 치수, 해칭)로 바꿔서
**이후 해석은 DXF 리더와 완전히 같은 코드**가 합니다 (투상도, 회전체 단면, 옆 구멍, 탭, 공차, 실루엣·단면 검증).

## 1. PDF에는 CAD 정보가 없다 → 다시 만든다

| CAD 개념 | PDF에 남는 것 | 복원 방법 |
|---|---|---|
| 레이어 (외형/치수/중심선) | 선 굵기 | 가장 굵은 굵기 묶음 = 외형선, 더 가는 실선 = 치수선·보조선·지시선 (제외) |
| 선 종류 (숨은선/중심선) | PDF 점선 패턴, 또는 짧은 선 조각들 | 패턴/조각 길이가 일정 = 숨은선, 길고 짧게 번갈아 = 중심선. 조각 하나짜리 짧은 숨은선은 같은 펜 굵기로 판별 |
| 원·호 | 베지어 곡선 (원 = 4조각) | 곡선 끝점(곡선 위의 점)으로 원을 맞춤 — 베지어 중간점은 0.03% 부풀어 있어서 쓰지 않음. 잘게 쪼갠 폴리라인도 원으로 맞춤 |
| DIMENSION 객체 | 채워진 삼각형(화살표) + 선 + 글자 | 아래 2장 |
| 축척 | 없음 (단위 pt) | 치수 값 ÷ 잰 길이의 중앙값 → 1:1, 1:2, 2:1 … 표준 축척으로 맞춤 |
| HATCH | 가는 평행 사선 수십 개 | 일정 간격 평행선 6개 이상 = 해칭. 외형선이 만드는 닫힌 영역 중 그 선들이 들어 있는 곳 = 해칭 영역 |

## 2. 치수 복원

1. 채워진 작은 삼각형 = 화살표. 뾰족한 꼭짓점이 끝점, 그 반대 방향이 화살표 방향.
2. **화살표 쌍**: 같은 직선 위에서 서로 등을 댄 두 화살표(`<──>`, 안쪽 화살표)를 먼저, 그다음 서로 마주 보는 두 화살표(`──> <──`, 짧은 치수·작은 지름).
   두 끝점 사이 거리 = 그려진 길이.
3. **값 글자 배정**: 모든 (화살표 쌍, 숫자 글자) 조합의 거리를 구해 **가까운 것부터 전체에서** 짝을 지음 (치수마다 가까운 글자를 고르면 이웃 치수의 글자를 뺏음).
   1차 배정으로 축척을 구한 뒤, 그 축척에서 값이 3% 넘게 안 맞는 글자는 뒤로 미뤄 다시 배정.
4. 지름 원 위에서 끝나는 화살표 하나 + `Ø` / `R` 글자 = 지름·반지름 지시선.
5. 글자 해석은 DXF와 같은 규칙: `4-Ø6.6`(개수), `R5`, `1.5x45°`(모따기), `C'BORE Ø9.5 DP5.4`, `M6`, 공차.

## 2-1. 화살표가 아닌 끝 표시 · 여러 쪽 · 상세도 (v0.4)

- **사선(틱)·점 끝 표시:** 가는 선 하나에 끝 표시가 정확히 두 개 있으면(선을 30~60°로 가로지르는 짧은 획의 가운데,
  또는 선 위의 작은 채운 원) 그 두 점을 바깥을 향한 화살표 한 쌍으로 바꿔서 같은 치수 코드가 읽음. 틱 획은 형상에서 뺌.
- **여러 쪽 PDF:** 기본은 선(그리기 경로)이 가장 많은 쪽 — 표지·부품표·주기 쪽을 건너뜀. 다른 쪽은
  `d2f run 도면.pdf --page 3` (MCP `d2f_extract`의 `page`). 쪽을 고르면 결과 폴더가 `<이름>_p3`.
- **상세도 축척:** 치수 문자와 그려진 길이가 표준 배율(2, 2.5, 4, 5, 10, 20, 1/2 …)만큼 다르고 그 치수가 정렬되지 않은 뷰
  (상세도) 쪽에 있으면 충돌(E107)이 아니라 그 뷰의 축척으로 읽음(INFO). DXF도 같음. `<>` 치수는 1:1 표로 셈해서,
  상세도 치수 몇 개가 도면 전체 축척을 바꾸지 못함.
- **짧은 중심선:** 조각으로 그린 짧은 중심선(긴 대시 1개 + 점)이 숨은선으로 읽히던 문제 — 도면의 숨은선 대시 길이와 비교해서 바로잡음.

## 3. 시험한 것

`tools/make_sample_pdf.py`가 샘플 DXF 9장을 CAD 내보내기처럼 PDF로 만듭니다: 실제 글자(글리프 외곽선 아님),
층별 선 굵기, 채운 화살표, 베지어 원, 해칭은 낱개 선. 점선은 **두 방식**(PDF 점선 패턴 / 조각 선) 모두, 플랜지는 **1:2 축척**.
단위 테스트가 DXF와 같은 정답(크기·구멍 위치·회전 프로파일·부피)을 요구하고, 회귀 테스트가 Fusion에서 빌드까지 확인합니다.

## 4. 아직 안 되는 것

- 글자가 **외곽선(path)으로 변환된 PDF** — 숫자를 읽을 수 없음 (일부 CAD의 "글꼴을 곡선으로" 옵션). 치수 없이 형상만 읽고 경고
- AutoCAD SHX 글꼴이 선으로 그려진 PDF — 위와 같음
- 상세도의 **형상**은 쓰지 않음 (치수만 그 축척으로 읽음)
- 여러 쪽 PDF를 한 번에 여러 부품으로 — 쪽마다 `--page`로 따로 실행
- 동심원 지름 치수 두 개의 화살표가 한 직선 위에 있으면 서로 짝지어질 수 있음 (지름 치수 각도를 다르게 두면 됨)
- 실제 업체 PDF로는 아직 시험 전 — `samples/drawings/real/`에 넣어 주시면 회귀 테스트에 추가합니다
