## 진행 방식

래스터 이미지는 Phase 4 범위라 **이미지 → 스펙** 단계는 Claude가 직접 도면을 읽어 작성했다
(Phase 4에서 자동화할 비전 판독을 사람이 지켜보는 상태로 대신 수행). 그 뒤 스펙 검증 → Fusion 빌드 →
실측 검증 → 알림은 실제 파이프라인(`run.bat`)으로 실행했다.

## 모델에 없거나 근사한 것 (스펙 `notes`에 기록)

| 항목 | 처리 |
|---|---|
| 오른쪽 팔과 귀 사이 R15 오목 필렛 | 없음 — 오목 모서리 선택기 미구현 |
| 왼쪽 바닥 포켓 (숨은선이 팔 테이퍼를 10 안쪽으로 따라감) | R20 장공 + 폭 40 사각형으로 근사, `pocket_end`는 추론값(경고) |
| 정면도 가운데 아래쪽 폭 10 숨은선 쌍 | 공동 내부 빈 공간과 겹쳐 의미 불명 — 단면 A-A/B-B 없음, 해석 보류 |
| 오른쪽 슬릿 깊이 | 관통으로 가정 |
| 위쪽 20 Drill 깊이 | 보스 + 윗벽(15)까지 → 공동과 연결 |

## 이번 테스트로 고친 것

| 증상 | 조치 |
|---|---|
| 공동 안쪽 모서리에 R10을 걸 방법이 없음 | 선택기 `vertical_edges:<feature>` 추가 (그 피처가 만든 면의 수직 모서리) |
| 필렛·반원 끝(1/4, 1/2 원통)까지 "구멍"으로 셈 | 원통면 넓이로 감싼 각도를 계산해 90% 미만은 `partial`로 분리 (이번 모델에서 8개 제외) |
| 원형 보스 위 구멍을 "외곽 밖"으로 오판 (E205) | 사전 검사가 사각형뿐 아니라 원·다각형도 외곽으로 인정 |
| 필렛 크기 검사가 엉뚱한 사각형(슬릿 폭 10)과 비교 | 필렛을 거는 피처의 스케치 사각형하고만 비교 |
| 슬릿 관통 컷 자동 보정 거리가 0 mm → "입력 인수가 잘못됨" | 일반 돌출도 스케치 평면·높이를 넘기고, 0 이하이면 몸체 전체 길이 사용 |
| 기울어진 변이 있는 다각형 스케치가 미완전 구속 | 기울어진 변의 꼭짓점도 원점 기준 치수로 고정 |

## Phase 4에 주는 의미

- 휴대폰 캡처 수준의 3각법 도면도 비전 판독으로 **치수가 맞는 파라메트릭 모델**까지 갈 수 있음을 확인
- 판독 결과는 지금 스펙 형식(`source` / `confidence` / `notes`)에 그대로 담기므로, 자동 판독기는 **이 스펙을 만들어 내는 것**만 하면 됨
- 사람이 읽어도 애매했던 곳(숨은선 의미, 깊이 미표기)은 자동 판독에서 BLOCK 질문으로 내보내야 함
- 빌더에 필요한 다음 기능: 오목 필렛(R15), 오프셋 외곽(테이퍼 따라가는 포켓), 단면도 읽기
